Hands-on · 25 minutes

The prompts, in order

Each prompt is written with GCES (Goal, Context, Expectations, Source). Run them in the same chat so Copilot keeps the file in view.

Prompt 1: Orient before you analyse

I have attached a workbook from a chemical plant with four sheets: Production, QA_Results, Maintenance_Log and Dept_Spend. Before any analysis, describe: - what one row represents in each sheet, and the date range covered - any data-quality problems you notice: blank cells, duplicate rows, values that look like the wrong unit or are far out of line Use a short table per sheet. Do not analyse trends yet.

Prompt 2: Trends and outliers

Using the Production sheet, calculate weekly attainment (Actual_t divided by Planned_t, as a %) for each line. Show a table of attainment by week and line, flag every week below 90%, and describe the trend for each line in one sentence. Tell me how you handled any blank or suspicious values.

Prompt 3: Explain the flagged weeks across sheets

For each week you flagged, look in Maintenance_Log and QA_Results for anything on the same line around the same time that could explain it. For each link you suggest, label it clearly as either EVIDENCE (shown in the data, with the row reference) or GUESS (your interpretation).

Prompt 4: Check the QA results yourself

Spec limits: Purity_pct at least 99.80, Moisture_ppm at most 300, Colour_APHA at most 10. A batch fails if any one result is outside its limit. Check every batch in QA_Results against these limits yourself. Do not rely on the Result column. 1. List any batch where your check disagrees with the Result column. 2. Count failing batches per line, and say which limit each one failed. 3. Tell me if any Batch_ID appears more than once.

Prompt 5: Formula and summary table

Give me an Excel formula for a new column Attainment_pct in the Production table, and a summary table showing total Planned_t, total Actual_t and average attainment by line. Explain the formula in one sentence so I can check it.

Prompt 6: The money

Using Dept_Spend, compare actual against budget for Q3 by department, in SGD and %. Which overspends could be linked to events in the maintenance or QA data? Label each link EVIDENCE or GUESS.

Prompt 7: Management summary

Write a summary of this quarter for the plant manager: 5 bullet points, plain language, most important first. After the bullets, list every number you used and mark any you are not certain about.
On the add-on licence? Also try: "Add a column Attainment_pct to the Production table" and "Create a line chart of attainment by week for each line." If you use Power BI, this is the same kind of question you would build a dashboard for. Copilot gives you a first pass in minutes, and Power BI remains the right tool for the recurring dashboard.
The step that matters most

Critically check the analysis

Before any number is used, find out what the tool assumed, what it ignored, and what a human must confirm.

Ask yourselfHow to check
Did it notice the data-quality problems, and what did it do with them?Compare its answer to Prompt 1 with what you see when you sort or filter each column yourself
Is the total output believable for three lines over 12 weeks?Rough sense check: three lines of a few hundred tonnes a week, times 12 weeks
Did it trust the Result column or really check the limits?Filter QA_Results for any value outside a limit and compare
Are its explanations evidence or guesses?Open the rows it cites. No row reference means it is a guess
Is one key figure right?Recalculate it yourself with a formula (below)
Check formulas (in the .xlsx, the tables are tblProduction, tblQAResults, tblMaintenanceLog, tblDeptSpend)
=SUMIFS(tblProduction[Actual_t], tblProduction[Line], "L2") =COUNTBLANK(tblProduction[Actual_t]) =MAX(tblProduction[Actual_t]) =COUNTIFS(tblQAResults[Moisture_ppm], ">300") =ROWS(tblQAResults[Batch_ID]) - ROWS(UNIQUE(tblQAResults[Batch_ID])) =SUMIFS(tblMaintenanceLog[Cost_SGD], tblMaintenanceLog[Equipment], "P-201") =SUMIFS(tblDeptSpend[Actual_SGD], tblDeptSpend[Department], "Maintenance") - SUMIFS(tblDeptSpend[Budget_SGD], tblDeptSpend[Department], "Maintenance")
