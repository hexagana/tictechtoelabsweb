The COPILOT Function — Oil & Gas Use Cases

Eleven ready-to-run demonstrations of Excel's =COPILOT() function on realistic oil, gas and process data. Paste the sample table, paste the formula, and Excel reads the text and reasons about it — no Power BI, no Python, no advanced Excel skills.

📊 11 use cases
📋 22 copy blocks
⚡ 2 min each

How to run any of these

  1. Open a blank Excel sheet
  2. Copy the sample data and paste it into cell A1
  3. Copy the formula and paste it into an empty cell to the right — C1 works well
  4. Press Enter and wait a few seconds for Copilot to think
  5. Try the push it further prompt to take the answer one step deeper
Before you start: the =COPILOT() function needs a Microsoft 365 Copilot licence and a build of Excel where the function is switched on. If Excel returns #NAME?, the function is not available on that account yet — run the demo from a machine where it is, rather than troubleshooting it live.

Safety Incident Analysis

Turns free-text incident reports into consistent categories — the job a supervisor usually does by hand every Monday.

Employee Sentiment — Bonus Demo

The one that gets the reaction. Unstructured comments become themes and sentiment with no Power BI, no Python, no advanced Excel.

1 Sample data paste into cell A1
Employee Comment
The permit process takes too long during shutdowns
Equipment availability has improved significantly
Communication between day and night shifts needs improvement
The new safety training was very useful
We experienced delays due to spare part shortages
Management support during the turnaround was excellent
Maintenance planning has become more organized
2 Formula range A2:A8
=COPILOT("Perform sentiment analysis and identify the top themes mentioned by employees", A2:A8)
Push it further: Group the negative themes by department and suggest one owner for each.

💡 Running these in a session

  • Start with number 11. Sentiment analysis on plain employee comments gets the strongest reaction, and everything else makes sense afterwards.
  • Change one word in a prompt and re-run it — swapping summarise for act as a petroleum engineer and summarise shows how much the role instruction matters.
  • The formula reads a range of cells, not one cell. If you widen the sample data, widen the range to match.
  • Answers vary slightly between runs. That is worth saying out loud — it is a reasoning engine, not a lookup table.
  • Ask participants to swap in their own incident log or observation list. The demo lands hardest on data they recognise.
