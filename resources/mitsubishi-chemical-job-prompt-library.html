💡 Prompt Tips

To get the best results from any of these prompts:

  • Paste the entire prompt into Microsoft 365 Copilot in one go — don't trim it. The last line asks Copilot to show the full HTML code in the console so you can copy it straight out. If the code stops halfway, reply “Continue the code exactly from where you stopped.”
  • Save the code as a .html file (for example in Notepad, Save as “my-cockpit.html”, encoding UTF-8) and double-click it to open it in Edge.
  • Pick more than one — build the tool that saves you the most time first, then come back for the others or the cross-function tools.
  • After the first build, ask for iterations: “Add a dark mode toggle”, “Add an Export to CSV button so I can open it in Excel”, or “Rename the plant areas to match ours.”
  • If the output feels generic, add context at the end: “Use terminology familiar to a continuous-process MMA monomer plant on Jurong Island.”
  • Maintenance & Engineering has five colleagues in one section — each has their own card, so build yours and swap the finished pages between you; the work order, permit and calibration tools connect naturally.
  • Keep company data out of the AI tool — never paste real process conditions, catalyst or formulation details, production and cost figures, customer names, pricing or personal data into a prompt. Build with the seeded sample data first, then type your real figures into the finished page in your own browser: localStorage keeps them on your laptop, not in the AI.
  • Keep the unified framing in mind: each page should replace 3 common Excel files and 2 recurring emails in your job.
