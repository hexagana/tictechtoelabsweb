SWTS · SFDW 2.0 · Day 2 · Decision Support

The Decision Metrics — Build Prompts

Twenty-six strategic thinking models from The Decision Book by Mikael Krogerus & Roman Tschäppeler, turned into copy-paste prompts. Each one builds you a working tool you can fill in with a real decision you are facing right now — not a diagram to admire, an instrument to use.

🎯 4 parts
🧠 26 models
⚡ 26 build prompts

How to use this guide

Pick a model that matches a decision you are actually carrying, then copy its build prompt straight into an AI tool — Microsoft Copilot, ChatGPT, Claude, or Gemini. Every prompt is self-contained and produces a single HTML page with embedded CSS and vanilla JavaScript that you can open in any browser, fill in with your own situation, and keep. Each one ends with an instruction to show the full HTML source code in the code console so you can copy it directly. Do not try to build all twenty-six — choose the one that fits the decision in front of you, build it, and use it today. The models are grouped as the book groups them: improving your own decisions, understanding yourself, understanding others and risk, then leading teams.

💡 How to get the most from these

These models earn their keep only when pointed at something real:

  • Bring a live decision. Do not build a model to admire it — pick the one that matches a call you are actually carrying this week.
  • Paste the entire prompt into your AI tool in one go — don't trim it. The last line asks the AI to show the full HTML code in the console so you can copy it straight out.
  • After the first build, ask for iterations: "Replace the seed data with my actual team" or "Add a print stylesheet so I can take this into the meeting."
  • Several of these are better run with your team than alone — the Johari Window, Six Thinking Hats, Appreciative Inquiry and the Team Performance model are all designed for a room, not a desk.
  • The remaining models in The Decision Book are principles rather than instruments — Black Swan, cognitive dissonance, choice overload, the prisoner's dilemma. They are worth knowing but there is nothing to fill in, so they are not built here.
