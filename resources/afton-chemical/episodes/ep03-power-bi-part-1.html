Topic 2

Clean Your Data Using Power Query (Excel)

Before using Power BI, you must ensure your data is clean and consistent.

Step 1: Review the Data for Issues and use Power Query to tidy up your raw data

  1. On Excel, choose the Data tab.
  2. Select Get Data → From File and choose the Excel file you want to tidy up.

Then choose the Excel file called Sample_Sales_Data.

In the Navigator window:

  1. Select Sales Data.
  2. Click on Transform Data.
  • Check for inconsistencies in:
    • Product names
    • Region names (e.g. WE, West)
    • Sales Amount format
    • Date formats
    • Customer IDs
  • Understand why standardisation is critical for accurate reporting

Step 2: Split and Rename Columns

  • Identify combined columns (e.g. Product + Category)
  • Use Split Column:
    • Choose a delimiter (e.g. space or symbol)
  • Rename columns clearly so they make sense in charts and dashboards
  1. Right-click on the Product Name header.
  2. Select Split Column.
  3. Choose By Delimiter.

In the Split Column by Delimiter dialog:

  1. Ensure Space is selected as the delimiter.
  2. Ensure None is selected as the Quote Character (under Advanced options).
  1. Double-click on the column A header and rename column A to "Product".
  2. Double-click on the column B header and rename column B to "Category".

Step 3: Replace Values for Consistency

  • Use Replace Values to standardise data
  • Example:
    • Replace WE with West
  • Ensure the same naming is used across the entire dataset
  1. Click on the Region column header to highlight the entire column.
  2. Choose the Home tab.
  3. Click on Replace Values.
  4. Enter WE into the Value To Find box.
  5. Enter West into the Replace With box.

Step 4: Change format for Sales Amount

  • Click on the format icon to change to currency
  1. Click on the format icon in the Sales Amount column header.
  2. Choose Currency.

Step 5: Format and Merge Columns

  • Format numeric columns:
    • Change sales values to currency
  • Merge date columns:
    • Combine Day, Month, and Year into one column
    • Use a custom separator if needed
  • Convert the merged column to a proper date format
  1. Hold down Shift and click on the Day, Month and Year columns to select all 3 columns.
  2. Right-click and choose Merge Columns.

In the Merge Columns dialog, choose the --Custom-- separator.

  1. Enter / into the empty box.
  2. Enter Date into the New column name box.
  1. Click on the column format icon of the new Date column.
  2. Choose Date.

Step 6: Extract Customer IDs

  • Identify customer ID fields mixed with text
  • Use Extract Text After Delimiter
  • Apply the function multiple times if needed:
    • Remove text
    • Remove hyphens
  • Result should be a clean numeric customer ID
  1. Click on the Customer ID column.
  2. Click on the Transform menu tab.
  3. Click on Extract.
  4. Click on Text After Delimiter.

Enter - (a hyphen) into the Delimiter box.

  1. Check and see if the first part of the text has been removed.
  2. Click on Extract again.
  3. Enter - into the Delimiter box. This will remove the second part of the text and only extract the number in the Customer ID column.

Topic 5

Creating Your First Dashboard on Power BI

Import your cleaned Excel data into Power BI Desktop, build and format visuals, and copy formatting across charts.

1) Importing and Connecting Cleaned Data in Power BI

You will try the process of importing a cleaned Excel dataset into Power BI, emphasizing the importance of saving the cleaned file and selecting the correct worksheet for analysis.

  • Starting a New Power BI Report: open Power BI and begin with a fresh, blank report to ensure a clean workspace for the new data analysis.
  • Importing Cleaned Excel Data: You will connect Power BI to the cleaned Excel file by selecting 'Excel Workbook,' choosing the appropriate file, and ensuring the correct worksheet ('clean up data') is loaded for analysis.
  • Importance of Saving Cleaned Data: Saving the newly cleaned Excel file is important before importing it into Power BI to avoid issues with outdated or unsaved changes.
  1. In the Navigator, choose the cleaned up data sheet (CLEAN UP DATA) from the Excel file.
  2. Click on Load.

2) Creating and Customizing Visuals in Power BI

You can create multiple types of visuals, such as column and pie charts, assign data fields, and customize their appearance, including colors, grid lines, and axis labels, to enhance dashboard clarity.

Adding and Assigning Data to Visuals

You will now add visuals like column and pie charts to the Power BI canvas, assign relevant data fields (e.g., product, sales amount, region), and explore the mapping of data to axes for meaningful representation.

  1. Choose a chart from the Visualizations pane.
  2. The chart will appear on your canvas.
  1. Choose 2 types of data from the Data pane – Product and Sales Amount.
  2. The data will be reflected on the bar chart.

Customizing Chart Colors

You will try the process of renaming the Axis, assigning individual colors to different products within a chart, using the 'format visual' options to distinguish between categories and improve visual clarity, especially when dealing with many variables.

To rename the axis:

  1. Choose the Build visual tab.
  2. Click on the dropdown for the axis field.
  3. Click Rename for this visual.
  4. Rename it to Sales Amount.

To change bar chart colours:

  1. Select the Format visual tab.
  2. Click the Columns dropdown.
  3. Choose the individual products (under Apply settings to → Categories).
  4. Assign a colour.

Adjusting Grid Lines and Axis Formatting

You will now see how to modify grid line visibility and style, and how to adjust axis value formatting (e.g., switching between thousands and millions) to make charts more readable and precise.

Changing the gridlines for your charts:

  1. Select Format visual.
  2. Choose the Visual tab.
  3. Click the Gridlines dropdown.
  4. Choose a Line style (Solid, Dashed, Dotted or Custom).
  5. You can choose the colours too.

To change the denominator (display unit) values on the axis:

  1. Click on Format visual.
  2. Choose Visual.
  3. Open the Y-axis section and choose Values.
  4. Select the Display units dropdown (for example, Thousands or Millions).

Displaying Exact Data Labels and Currency Formatting

You will now learn how to enable and customize data labels for exact values on charts, and how to apply currency formatting to sales figures to avoid confusion and ensure clarity for management and stakeholders.

To turn on labels for each bar chart:

  1. Select Format visual.
  2. Select Visual.
  3. Select Columns.
  4. Turn on Data labels.

To change the figures to show currency format:

  1. Choose Format visual.
  2. Choose the General tab.
  3. Click the Data format dropdown.
  4. Under the Apply settings to dropdown, select Sales Amount.
  5. Under the Format dropdown, choose Currency.

Enhancing Chart Borders and Aesthetics

You can add and customize chart borders, including enabling rounded corners, to improve the overall visual appeal of the dashboard.

To make the border of the charts rounded:

  1. Choose Format visual.
  2. Choose the General tab.
  3. Click the Effects dropdown.
  4. Choose Visual border.
  5. Choose Rounded corners.

3) Efficient Dashboard Design and Format Replication

You will try and use the Format Painter tool in Power BI to replicate design and formatting across multiple charts, streamlining the dashboard creation process for the team.

  • Using Format Painter for Consistency: You can use the Format Painter tool to copy formatting from one chart to others, ensuring a consistent design across all visuals without the need to manually replicate each formatting step.

To replicate the design from one chart to another:

  1. Select the chart that you have already formatted.
  2. Click on Format painter (Home tab).
  3. Click on the new chart that you want to replicate the design format to.

Practice Exercises

Four hands-on exercises to build reports and dashboards from the practice files. Download the files from Practice files below.

Exercise 1: Regional Sales Report

Your Task: Create a report showing sales by REGION (instead of by product).

Steps to Complete:

  1. Open a new Power BI file (File → New)
  2. Load Sample_Sales_Data.xlsx using Get Data
  3. Create a bar chart showing sales by region
    • X-axis: Region
    • Y-axis: Sales Amount
  4. Create a card showing total sales
  5. Create a table with Region and Sales Amount columns
  6. Arrange visuals neatly (chart top-left, card top-right, table bottom)
  7. Save as "Regional Sales Report"

Exercise 2: Store Performance Dashboard

Your Task: Create a dashboard showing which stores perform best.

File to Use: Store_Performance.xlsx (practice file)

Steps to Complete:

  1. Load Store_Performance.xlsx using Get Data
  2. Create bar chart: Revenue by Store Name
  3. Create card: Total Revenue (Sum of Monthly Revenue)
  4. Create second card: Total Customers (Sum of Customer Count)
  5. Create table: Store Name, City, Monthly Revenue, Customer Count
  6. Arrange visuals in organized layout
  7. Save as "Store Performance Dashboard"

Exercise 3: Employee Hours Analysis

Your Task: Create a report analyzing employee work hours.

File to Use: Employee_Hours.xlsx (practice file)

Steps to Complete:

  1. Load Employee_Hours.xlsx
  2. Create bar chart: Hours Worked by Department
  3. Create card: Total Hours Worked
  4. Create second bar chart: Hours Worked by Employee Name
  5. Create table: Employee Name, Department, Hours Worked
  6. Arrange all visuals clearly
  7. Save as "Employee Hours Report"

Exercise 4: Customer Feedback Summary

Your Task: Create a report showing customer satisfaction by service type.

File to Use: Customer_Feedback.xlsx (practice file)

Steps to Complete:

  1. Load Customer_Feedback.xlsx
  2. Create bar chart: Average Rating by Service Type
    • Important: Change from "Sum" to "Average"
    • Click "Sum of Rating" in Visualizations pane
    • Select "Average" instead
  3. Create card: Average Rating (overall)
  4. Create second card: Total Responses (Count of Customer ID)
  5. Create table: Service Type, Rating (average), Month
  6. Save as "Customer Satisfaction Report"
