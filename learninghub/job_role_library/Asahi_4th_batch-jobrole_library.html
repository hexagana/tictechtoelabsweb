Role-Based Webpages + Build Prompts

A curated set of webpage concepts aligned to the participant roles in the Asahi Kasei Plastics 4th Batch SFDW programme — each role gets copy-paste prompts that produce working internal tools, each one replacing 3 common Excel files and 2 recurring emails in the daily job of manufacturing engineering plastics from chemical feedstock.

🎯 8 job functions

How to use this guide

Find the section matching your job function, then copy any build prompt straight into an AI tool — Microsoft Copilot, ChatGPT, Claude, or Gemini. Each function offers two to four tools — pick the one that speeds up the job you care about most. Every prompt is self-contained and produces a single HTML page with embedded CSS and vanilla JavaScript that you can preview in any browser and adapt to your team's actual data, and every prompt ends with an instruction to show the full HTML source code in the code console so you can copy it directly. Several roles are shared by more than one participant — two Accounts Executives, three Logistics Executives, two Senior Executives — and you all draw from the same section. The framing throughout is the same: "Build a browser-based, personal productivity cockpit that replaces 3 common Excel files and 2 recurring emails in your job."

💡 Prompt Tips

To get the best results from any of these prompts:

  • Paste the entire prompt into your AI tool in one go — don't trim it. The last line asks the AI to show the full HTML code in the console so you can copy it straight out.
  • Pick more than one — your function has two to four tools; build the one that saves you the most time first, then come back for the others.
  • After the first build, ask for iterations: "Add a dark mode toggle" or "Replace the seed data with my actual grades, customers, or supplier list."
  • If the output feels generic, add context at the end: "Use terminology familiar to an engineering-plastics compounding and moulding plant."
  • Keep company data out of the tool while you are learning — build with the seeded sample data first, then swap in real figures once the page runs locally in your own browser.
  • Keep the unified framing in mind: each page should replace 3 common Excel files and 2 recurring emails in your job.
