How to use this guide

Find the section matching your job function, then copy any build prompt straight into an AI tool — Microsoft Copilot, ChatGPT, Claude, or Gemini. Each function offers two to four tools — pick the one that speeds up the job you care about most. Every prompt is self-contained and produces a single HTML page with embedded CSS and vanilla JavaScript that you can preview in any browser and adapt to your team's actual data, and every prompt ends with an instruction to show the full HTML source code in the code console so you can copy it directly. This roster runs the whole product path — from foundry wafer starts and die bank, through bump, die prep and assembly, into test, tape and reel and out to the customer — so the Product & Test Engineering and Planning sections carry four tools each, while Sourcing, Packaging, Programs, Sales and Corporate Services carry three. The framing throughout is the same: “Build a browser-based, personal productivity cockpit that replaces 3 common Excel files and 2 recurring emails in your job.”
