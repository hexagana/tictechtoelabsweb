SFDW 2.0 (General) · 20 & 21 August 2026

Role-Based Webpages + Build Prompts

A curated set of webpage concepts aligned to the participant roles in this two-day SkillsFuture for Digital Workplace 2.0 programme — built for a ready-mix concrete, cement and building materials group. Each role gets copy-paste prompts that produce working internal tools, each replacing 3 Excel files and 2 recurring emails in the daily job.

🎯 6 job functions
👥 16 participant roles
⚡ 24 build prompts

How to use this guide

Find the section matching your job function, then copy any build prompt straight into an AI tool — Microsoft Copilot, ChatGPT, Claude, or Gemini. Each function offers four tools — pick the one that speeds up the job you care about most. Every prompt is self-contained and produces a single HTML page with embedded CSS and vanilla JavaScript that you can preview in any browser and adapt to your plant's actual data, and every prompt ends with an instruction to show the full HTML source code in the code console so you can copy it directly. Most functions are shared by two or more participants (Operations & Delivery, QA & Laboratory, Technical & Engineering, Commercial & Credit) — you all draw from the same section. The framing throughout is the same: "Build a browser-based, personal productivity cockpit that replaces 3 common Excel files and 2 recurring emails in your job."
