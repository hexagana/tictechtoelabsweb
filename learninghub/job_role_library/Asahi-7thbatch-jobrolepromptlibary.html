How to use this guide

Find the section matching your job function, then copy any build prompt straight into an AI tool — Microsoft Copilot, ChatGPT, Claude, or Gemini. Each function offers two to four tools — pick the one that speeds up the job you care about most. Every prompt is self-contained and produces a single HTML page with embedded CSS and vanilla JavaScript that you can preview in any browser and adapt to your own machines, grades and customers, and every prompt ends with an instruction to show the full HTML source code in the code console so you can copy it directly. This class is a shop-floor group — nine Senior Technicians, seven Technicians and a Day Technician make up seventeen of the twenty-four seats — so the Technicians section carries the most tools and those pages are built for a tablet or phone at the machine rather than a desk. The framing throughout is the same: “Build a browser-based tool that replaces three forms or files and two recurring messages in your job.”

💡 Prompt Tips

To get the best results from any of these prompts:

  • Paste the entire prompt into your AI tool in one go — do not trim it. The last line asks the AI to show the full HTML code in the console so you can copy it straight out.
  • Pick more than one — your function has two to four tools; build the one that saves you the most time first, then come back for the others.
  • Technicians — there are sixteen of you sharing one section. Build different tools and swap the finished pages between you rather than all building the same one.
  • After the first build, ask for iterations: “Make the buttons bigger for use on a tablet with gloves on” or “Replace the seed data with my actual machine numbers and grades.”
  • If the output feels generic, add context at the end: “Use terminology familiar to an engineering-plastics compounding and moulding plant.”
  • Keep company data out of the tool while you are learning — build with the seeded sample data first, then swap in real figures once the page runs in your own browser.
  • Keep the framing in mind: each page should replace three forms or files and two recurring messages in your job.
