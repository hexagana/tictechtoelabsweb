Asahi Kasei Plastics Singapore · SFDW 2.0 · 5th Batch

Role-Based Webpages + Build Prompts

A curated set of webpage concepts aligned to the participant roles in the Asahi Kasei Plastics 5th Batch SFDW programme — each role gets copy-paste prompts that produce working internal tools, each one replacing 3 common Excel files and 2 recurring emails in the daily job of manufacturing engineering plastics from chemical feedstock.

🎯 7 job functions
👥 9 participant roles
⚡ 22 build prompts

How to use this guide

Find the section matching your job function, then copy any build prompt straight into an AI tool — Microsoft Copilot, ChatGPT, Claude, or Gemini. Each function offers two to four tools — pick the one that speeds up the job you care about most. Every prompt is self-contained and produces a single HTML page with embedded CSS and vanilla JavaScript that you can preview in any browser and adapt to your team's actual data, and every prompt ends with an instruction to show the full HTML source code in the code console so you can copy it directly. This batch is engineering-heavy — four Engineers, a Senior Engineer, a Staff Engineer and a TS&D Engineer between them make up more than half the room — so the Engineering and Technical Service sections carry the most tools, and two General Managers share the leadership section. The framing throughout is the same: “Build a browser-based, personal productivity cockpit that replaces 3 common Excel files and 2 recurring emails in your job.”

💡 Prompt Tips

To get the best results from any of these prompts:

  • Paste the entire prompt into your AI tool in one go — don't trim it. The last line asks the AI to show the full HTML code in the console so you can copy it straight out.
  • Pick more than one — your function has two to four tools; build the one that saves you the most time first, then come back for the others.
  • After the first build, ask for iterations: “Add a dark mode toggle” or “Replace the seed data with my actual grades, customers, or supplier list.”
  • If the output feels generic, add context at the end: “Use terminology familiar to an engineering-plastics compounding and moulding plant.”
  • Engineers — you share a section with three colleagues. Build different tools and swap the finished pages between you rather than all building the same one.
  • Keep company data out of the tool while you are learning — build with the seeded sample data first, then swap in real figures once the page runs locally in your own browser.
  • Keep the unified framing in mind: each page should replace 3 common Excel files and 2 recurring emails in your job.
