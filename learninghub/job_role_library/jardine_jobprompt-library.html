Jardine Engineering · 2-Day SFDW 2.0 (General) · 13 & 14 Aug 2026

Role-Based Webpages + Build Prompts

A curated set of webpage concepts aligned to the participant roles in the Jardine Engineering (Singapore) 2-Day SFDW programme — each role gets copy-paste prompts that produce working internal tools, each one replacing 3 common Excel files and 2 recurring emails in the daily job across an engineering-services, facilities, and projects operation.

🎯 8 job functions
👥 13 participant roles
⚡ 21 build prompts

How to use this guide

Find the section matching your job function, then copy any build prompt straight into an AI tool — Microsoft Copilot, ChatGPT, Claude, or Gemini. Each function offers two or three tools — pick the one that speeds up the job you care about most. Every prompt is self-contained and produces a single HTML page with embedded CSS and vanilla JavaScript that you can preview in any browser and adapt to your team's actual data, and every prompt ends with an instruction to show the full HTML source code in the code console so you can copy it directly. Several roles are shared by more than one participant (two People & Culture Executives, two Safety Officers) or sit in the same function (Finance is shared by the Executive and Senior Executive; Administration by the Admin Assistant and Admin Executive; Technical Service by the Manager and the Engineer) — you all draw from the same section. The framing throughout is the same: "Build a browser-based, personal productivity cockpit that replaces 3 common Excel files and 2 recurring emails in your job."
