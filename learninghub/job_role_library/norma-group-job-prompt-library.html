NORMA Group Asia Pacific · SFDW 2.0

Role-Based Webpages + Build Prompts

A curated set of webpage concepts aligned to the participant roles in the NORMA Group Asia Pacific SFDW 2.0 class — each role gets copy-paste prompts that produce working internal tools, each one replacing 3 common Excel files and 2 recurring emails in the daily work of running HR, reward, learning, legal, IT, marketing, product management and finance across Asia Pacific.

🎯 8 job functions
👥 11 participants
⚡ 23 build prompts

How to use this guide

Find the section matching your job function, then copy any build prompt straight into an AI tool — Microsoft Copilot, ChatGPT, Claude, or Gemini. Each function offers two to five tools — pick the one that speeds up the job you care about most. Every prompt is self-contained and produces a single HTML page with embedded CSS and vanilla JavaScript that you can preview in any browser and adapt to your team's actual data, and every prompt ends with an instruction to show the full HTML source code in the code console so you can copy it directly. This class is weighted toward HR (five of the eleven participants), so Regional HR & HR Business Partnering carries five tools and Compensation & Benefits and Learning & OD get two each; legal, IT field service, marketing, product management and finance each get tools written for their own job, and people managers get a team cockpit in the last section. The framing throughout is the same: “Build a browser-based, personal productivity cockpit that replaces 3 common Excel files and 2 recurring emails in your job.”

💡 Prompt Tips

To get the best results from any of these prompts:

  • Paste the entire prompt into your AI tool in one go — don't trim it. The last line asks the AI to show the full HTML code in the console so you can copy it straight out.
  • Pick more than one — your function has two to five tools; build the one that saves you the most time first, then come back for the others.
  • After the first build, ask for iterations: “Add a dark mode toggle” or “Replace the seed data with our real country list, grades or product families.”
  • If the output feels generic, add context at the end: “Use terminology familiar to a regional HQ of an industrial manufacturer with plants across Asia Pacific.”
  • Five HR colleagues share the HR, reward and learning sections — build different tools and swap the finished pages between you rather than all building the same one.
  • Keep company data out of the AI tool — build with the seeded sample data first. Salaries, employee relations cases, medical and insurance claims, talent ratings, contracts, customer pricing and unpublished financials are Red data and never go into the prompt. The finished page stores its data only in your own browser, but check with HR and IT before you put real employee records into any local tool.
  • Keep the unified framing in mind: each page should replace 3 common Excel files and 2 recurring emails in your job.
